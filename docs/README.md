# Thaleryn Downtime Wiki

## Preview
Extract the ZIP and open index.html. The pages, tables, and navigation work without a build step.

## Publish with GitHub Pages
1. Create a GitHub repository such as thaleryn-wiki. Choose Public if anyone should be able to view the wiki.
2. Upload the extracted files directly into the repository root, so index.html is beside wiki.css. Commit to main.
3. In Settings → Pages, choose Deploy from a branch. Select main and / (root), then save.
4. Open the address shown in Settings → Pages once deployment finishes.

All links are relative so the wiki works at a repository URL. The optional Google Fonts have local fallbacks.

## Add a page
Duplicate an existing HTML article, rename it, then update its document title, heading, and main content. Add its filename to the home page cards and each page's sidebar. Update the previous and next links where it fits.

Source: Thaleryn Downtime Guide by Sheri Walls, November 15, 2026. Staff notes are excluded.
